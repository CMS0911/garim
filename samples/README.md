# 샘플 문서

모두 **합성 데이터**입니다. 실제 인물·주소·전화번호·주민등록번호와 무관하며, 데모 영상과 테스트에만 씁니다.

| 파일 | 쓰임 |
|---|---|
| `en_public_works.txt` | 영어 민원 → 온디바이스 경로(ON_DEVICE) 시연 |
| `ko_welfare.txt` | 한국어 민원 → 마스킹 후 클라우드 폴백(IN_CLOUD) 시연 |

`ko_welfare.txt`에는 규칙 검증용으로 주민등록번호·전화번호·주소·계좌번호 형식을 일부러 넣었습니다. 마스킹 결과에 이 문자열이 하나도 남지 않아야 합니다.
